About

LEONYX is a software company. We build automation and custom software for businesses that are losing time to manual work. We work remotely with teams in any time zone.

How we work

Smallest system that works

We fix the biggest problem first with the least software that solves it. More can be added later.

Everything can be inspected

Every automation keeps a log of what it did and why, so nothing runs as a black box.

People stay in the loop

Where a mistake is expensive, a person approves the step. The system prepares it, a person decides.

We say when software is not the answer

If a process should change before it is automated, we tell you that first.
